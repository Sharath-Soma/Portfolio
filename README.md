# Soma Sharath Kumar — Portfolio & Resume

A high-performance, responsive portfolio website for **Soma Sharath Kumar** — AI Engineer & Computer Science (Data Science) Graduate.

Built with an **Editorial Warm-Neutral Aesthetic**, high 60fps motion choreography via **Lenis** and **Framer Motion**, and strict data fidelity based exclusively on verified resume credentials.

---

## 🌟 Key Features

1. **60 FPS Lenis Scroll Engine & Progress Bar**
   - Decoupled `requestAnimationFrame` scroll progress indicator using GPU `transform: scaleX()`
   - Smooth exponential inertia scrolling with support for `prefers-reduced-motion`.

2. **Featured Case Studies & Project Gallery**
   - Dedicated modal views for each GitHub repository (*TalentForge*, *Digital Addressing System*, *Personal Fitness Tracker*, *EstateFlow AI*).
   - Interactive screenshot gallery toggles (Desktop View, Feature Breakdown, Analytics Dashboard, Mobile Viewport).
   - Problem, Solution, Key Features, Tech Stack, Technical Challenges, and Verified Metrics.

3. **Instant Project Search & Category Filtering**
   - Live query searching across tech stacks, titles, and feature descriptions.
   - Filter chips for `All`, `AI / NLP`, `Machine Learning`, `Data Science`, `Python`, and `Web Applications`.

4. **Clickable Skill Connections**
   - Click any skill item to open a connection drawer displaying every project and role where that skill was applied.
   - Smooth infinite marquee ticker with hover deceleration.

5. **Verified Certifications & Credentials**
   - Interactive certificate modals featuring zoom scale controls, verification summary copying, and proof document downloads (*Oracle Dev Gym Top 2%*, *AICTE Certificate of Merit*, *NPTEL Python*).

6. **Interactive Resume & Instant Copy**
   - Built-in full printable resume drawer accessible via top navigation or `Cmd+K` / `Ctrl+K` keyboard shortcut.
   - One-click text copying of complete formatted resume.

7. **Direct Mail Contact & Toast Feedback**
   - Direct mailto triggers combined with immediate clipboard email copy and animated toast notification.

## 🛠️ Technology Stack

- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Typography**: Plus Jakarta Sans, Playfair Display, JetBrains Mono
- **Animations & Scroll**: Lenis, Motion (Framer Motion)
- **Icons**: Lucide React

## 🚀 Development & Build Commands

```bash
# Install dependencies
npm install

# Run local development server (port 3000)
npm run dev

# Build for production
npm run build
```
